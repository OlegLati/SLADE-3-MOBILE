# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SLADE 3 Mobile, please report it privately to the project maintainer instead of opening a public issue.

Please include:

- a description of the vulnerability;
- steps to reproduce it;
- affected version, if known;
- any relevant logs or technical details.

Security issues will be reviewed as soon as possible.

## Scope

This policy applies to the SLADE 3 Mobile Android integration, including the Android application layer and the native integration layer maintained in this repository.

Third-party components may have their own security reporting procedures.
